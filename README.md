> **[TV Wieczór](https://tvwieczor.pl/)** to najszybszy, nowoczesny i zoptymalizowany pod kątem urządzeń mobilnych program telewizyjny dla Polski (Naziemna Telewizja Cyfrowa DVB-T2). Zaprojektowany, by natychmiast odpowiedzieć na pytanie: *Co dzisiaj obejrzeć w TV wieczorem?*

Generowany w 100% statycznie za pomocą **Astro SSG** i serwowany globalnie z sieci Edge **Cloudflare Pages** z czasem ładowania **< 0.3 sekundy**, z natywnym trybem ciemnym OLED i **bez inwazyjnych reklam**.

## 🌐 Oficjalne Portale i Główne Sekcje

Sprawdź aktualną ramówkę telewizyjną, program na żywo oraz hity wieczoru:

- 🌙 **[Program TV na dziś wieczór (Prime Time od 20:00)](https://tvwieczor.pl/)** — Zestawienie najlepszych filmów, seriali i programów rozrywkowych w polskiej telewizji w kluczowym paśmie wieczornym.
- 🔴 **[Co teraz w TV — Program na żywo](https://tvwieczor.pl/teraz/)** — Dynamiczny przewodnik z paskami postępu trwających audycji na żywo we wszystkich 26 stacjach naziemnych.
- 🍿 **[Filmy dzisiaj w TV z ocenami IMDb ⭐](https://tvwieczor.pl/filmy-dzisiaj/)** — Kompletny repertuar filmowy z wiarygodnymi ocenami widzów z całego świata (filtry dla hitów powyżej 7.0/10).
- 🏆 **[Sport w TV dzisiaj na żywo](https://tvwieczor.pl/sport-dzisiaj/)** — Transmisje meczów piłkarskich, skoków narciarskich, siatkówki i sportów walki w otwartych pasmach.
- 📺 **[Seriale dzisiaj w TV](https://tvwieczor.pl/seriale-dzisiaj/)** — Ulubione polskie tasiemce i seriale kryminalne (*Ojciec Mateusz*, *M jak miłość*, *Policjantki i Policjanci*).
- 📅 **[Program TV na jutro](https://tvwieczor.pl/jutro/)** — Wygodne planowanie jutrzejszych seansów i premier telewizyjnych.

## ⚡ Kluczowe Funkcjonalności (Killer Features)

1. **🌙 Pasmo Prime Time (godz. 20:00):**
   W Polsce główne hity wieczorne startują punktualnie o 20:00 (zaraz po *Wiadomościach/19:30* i *Faktach*). TV Wieczór eksponuje dokładnie to, co liczy się dla widza.
2. **⭐ Oceny IMDb & TMDb:**
   Integracja z bazą The Movie Database pozwala na natychmiastowe rozpoznanie arcydzieł od kina klasy B dzięki złotym gwiazdkom z oceną IMDb.
3. **🎨 Dedykowane Grafiki i Fallbacki:**
   Inteligentny parser z algorytmem oczyszczania polskich tytułów (obsługa numerów sezonów i dopisków) oraz 15 dedykowanych grafik tematycznych dla programów informacyjnych, pogody, sportu, seriali, dokumentów i religii.
4. **🚀 Błyskawiczna Indeksacja (Google Indexing API + IndexNow):**
   - Integracja z oficjalnym **Google Indexing API** (`programme@programmecesoir.iam.gserviceaccount.com`), gwarantująca aktualizację wyników wyszukiwania w kilka minut po wygenerowaniu ramówki.
   - Pings do protokołu **IndexNow** (Bing, Yandex, Seznam) z autoryzowanym kluczem weryfikacyjnym.
5. **📊 Dane Strukturalne Schema.org (JSON-LD):**
   Kompletne znaczniki `ItemList`, `BroadcastService`, `BroadcastEvent`, `Movie` oraz `TVSeries` zgodne z wytycznymi Google Rich Results.
6. **📱 Responsywny Design & Mobile-First:**
   Błyskawiczne działanie na smartfonach, obsługa gestów i zero irytujących reklam spowalniających przewijanie.

## 🛠️ Architektura i Polecenia CLI

```bash
# 1. Instalacja zależności
npm install

# 2. Pobranie ramówki EPG i wzbogacenie metadanymi TMDb/IMDb
npm run prebuild

# 3. Kompilacja do statycznego HTML/CSS (Astro SSG)
npm run build

# 4. Automatyczna weryfikacja poprawności generowanych podstron (TDD)
npm run postbuild

# 5. Natychmiastowe zgłoszenie zmian do Google i Bing
npm run ping
```
